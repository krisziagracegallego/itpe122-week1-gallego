 DevTools Investigation
B1 – Elements

Website: https://www.dorsu.edu.ph/

The Elements panel allows me to inspect the HTML structure of the website. I selected an element and temporarily changed its text to my full name.

After reloading the page, the original text returned because the change was temporary and was not saved to the original website.

B2 – Styles

The Styles panel allows me to inspect and modify the appearance of website elements using CSS.

I checked the color, font-family, and font-size properties. I also observed a crossed-out CSS property and changed the background color of the selected element.

B3 – Network

The Network panel shows the requests made by the website when it loads. It displays information such as request URLs, methods, status codes, file sizes, and loading times.

B4 Reflection

The website makes multiple requests because it needs to load different resources such as HTML, CSS, JavaScript, and images. These resources help display the website properly. Slow 4G can increase loading time because of the slower internet connection. Users in Davao Oriental with weak internet signals may experience slower website loading.
